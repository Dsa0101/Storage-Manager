# 🚀 Storage Manager — Official Roadmap & Progress

Public development roadmap and version history for **Storage Manager**, following the `X.Y.Z` standard versioning scheme.

---

## 📌 Versioning Scheme (`X.Y.Z`)

- **`X` (Major):** Comprehensive architectural overhaul, major redesign, and flagship features (e.g., `2.0.0`).
- **`Y` (UI/Features):** Core interface updates, multi-language expansion, and surface enhancements.
- **`Z` (Patch/Logic):** Performance optimization, stability fixes, SHA-256 integrity guards, and visual polish.

---

## 🗺️ Version History & Progress

### 🟢 Version 1.2.7 — Visual Refinement & Animations `[COMPLETED]`
- [x] **UI Polish:** Redesigned disk sunburst/donut charts, refreshed navigation panels, and updated Settings view.
- [x] **Algorithm Polish:** Optimized scanning engine to maintain minimal CPU/memory overhead on high-capacity volumes.
- [x] **Animation Engine:** Integrated fluid liquid-glass UI transitions and status indicators.

---

### 🟢 Version 1.2.8 — Lightweight Feature Update `[COMPLETED]`
> *Note: Advanced power-user features (CMD console and plugin system) were postponed to maintain lightweight efficiency and stability.*
- [x] **In-App Changelog:** Added native release notes view in Settings.
- [x] **Scan Optimizations:** Reduced background resource consumption during deep trash/cache analysis.
- [x] **Inter-Process Foundation:** Initial hooks prepared for future companion app communication.

---

### 🟢 Version 1.3.2 — Current Release `[STABLE / ACTIVE]`
- [x] **Orbital Hero UI:** Full visual overhaul featuring liquid-glass animations, dynamic radar scanning, and fluid donut metrics.
- [x] **Multi-Language Expansion:** Native support for English, Spanish, Portuguese, French, and German.
- [x] **SHA-256 Safety Guard:** Implemented byte-for-byte hash verification on Offload operations and Smart Cleanup confirmation guards.
- [x] **Accent Color Matching:** Full dynamic tinting integration with macOS system accent preferences.
- [x] **Settings Surface Migration:** Integrated droplet settings directly into Droppy’s native settings pane.

---

## 🟡 Upcoming Releases (v1.4.x) — Advanced Features

## 🔴 Future Vision — Version 2.0.0 (Major Release)
